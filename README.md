# EVSC Claude plugins

District skills for EVSC staff using Claude Desktop, in two sets:

- **Required** (`required/`): installed for everyone through the district's Claude setup, so staff don't need to do anything.
- **Optional** (`optional/`): reviewed by EVSC Technology. Staff choose which to install in Claude Desktop under **Settings → Plugins → Discover → Organization**.

## Required skills

| Skill | What it does |
| --- | --- |
| copy-ready-text | Puts text you'll paste somewhere else, such as an email or form field, in a box with a one-click copy button. |
| pii-safe-writing | Keeps names, student information and other personal details out of anything that will be saved, published or shared. |
| de-identify | Removes or generalizes information that could identify a student, family member or staff member before you share something. Ask Claude to "de-identify this." |
| project-setup-writer | Writes the title, description and instructions for a new Claude Project. |

## Optional skills

| Skill | What it does |
| --- | --- |
| plan-first | Before writing or changing code, scripts or formulas, Claude lists what it will change and waits for your go-ahead. |
| family-communication | Drafts clear, warm messages for parents and guardians: emails, newsletters, notices and replies to concerns. |
| family-translation | Translates family messages into other languages, keeping names, dates and details exact, with a back-translation to check. |
| lesson-planner | Plans lessons, units and sub plans around a standard you paste, with timing, checks for understanding and an exit ticket. |
| differentiate | Adapts texts, directions and tasks for different reading levels, English learners and extension, keeping the same learning goal. |
| rubric-builder | Builds analytic, single-point and checklist rubrics from your learning goals, with a student-friendly version. |
| quiz-builder | Writes quizzes, exit tickets and question banks with a separate answer key and mixed difficulty. |
| feedback-helper | Drafts specific glow-and-grow feedback on de-identified student work against your rubric or success criteria. |
| meeting-notes | Writes agendas and turns meeting notes into decisions, action items and a short summary. |
| accessible-docs | Checks documents, slides and emails for accessibility and writes alt text, with fixes for Google Docs and Word. |
| sheets-formulas | Writes and fixes Google Sheets and Excel formulas from your column layout, with a plain-language explanation. |
| google-apps-script | Applies Google Apps Script best practices when writing .gs code: the 6-minute limit, triggers, batching and error handling. |

These skills are instructions only. They don't connect to other services or run code.

Maintained by EVSC Technology. For help, contact the EVSC Technology help desk.
